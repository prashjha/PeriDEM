# Tutorial (legacy YAML helpers)

**Current input format is JSON** (`bin/PeriDEM -i input.json`). Use the checked-in
decks under [examples/](../examples/README.md) and the root
[README - Running simulations](../README.md#Running-simulations).

This folder keeps older Python helpers and notebooks that write `input.yaml`,
`.geo`, and particle-location CSVs. They record geometry and BC ideas for the
pre-JSON path. Their YAML is not a runnable deck for current `bin/PeriDEM`.
