Detailed Description

Trilinear hexahedron (VTK type 12) on reference cube [-1,1]^3.

Node ordering matches VTK / createUniformMesh: bottom face 0-1-2-3 (ξ,η at ζ=-1), top face 4-5-6-7 (ζ=+1).
